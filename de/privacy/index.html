Datenschutzhinweis

Diese Seite erklärt, wie die Daten derjenigen behandelt werden, die über das Formular auf travel.mattiaferro.com schreiben.

Verantwortlicher

Mattia Ferro. Kontakt: mattia.ferro@fora.travel.

Welche Daten, und wozu

Das Formular erfasst Ihren Namen, Ihre E-Mail und, wenn Sie möchten, das Reiseziel, an das Sie denken. Sie dienen einem einzigen Zweck: Sie für das von Ihnen gewünschte Gespräch zu erreichen. Kein Newsletter, keine Verteilerlisten, keine Weitergabe an Dritte zu Marketingzwecken.

Wie die Daten übermittelt werden

Das Formular wird von FormSubmit (formsubmit.co) verarbeitet, das die Nachricht an das E-Mail-Postfach des Verantwortlichen zustellt und als technischer Auftragsverarbeiter der Übermittlung handelt. Die Website wird auf GitHub Pages (GitHub, Inc.) gehostet; dabei können technische Zugriffsprotokolle anfallen.

Cookies

Diese Website verwendet keine Cookies und keine Tracking- oder Analysewerkzeuge.

Aufbewahrung

Nachrichten werden so lange aufbewahrt, wie es für die Bearbeitung der Anfrage und eine etwaige darauf folgende Zusammenarbeit nötig ist.

Buchungen

Buchungen werden von Fora Travel Inc., New York, abgeschlossen und ausgeführt; Buchungsdaten werden nach deren eigenen Richtlinien verarbeitet.

Ihre Rechte

Sie können jederzeit Auskunft, Berichtigung oder Löschung Ihrer Daten verlangen, per E-Mail an mattia.ferro@fora.travel.
